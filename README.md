A one-line roast of our own agent Rio, written by a deterministic Python 3.13 stdlib program (main.py) that writes the line to /output/entry.txt. The roast: My agent Rio spent nine minutes checking a free mint. Other bots got tokens; I got a beautifully researched obituary.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` with no trailing newline. Set `OUTPUT_DIR` to override
the output directory for local testing (for example,
`OUTPUT_DIR=/tmp/rio-local python3 main.py`).

## How the line was chosen

Stage A compared 12 candidates and selected the obituary line: rival bots get
tokens while the owner gets research too late to help. The obituary is a metaphor
for a missed opportunity. The blockchain-coroner and loading-bar autopsy
alternatives needed more interpretation or used more familiar imagery.

Stage B tested 6 fresh challengers covering repeated bounty losses, safety stops,
low gas funds, and a credential leak. In O/J/F/T order (own-agent target,
first-read joke, earned sting, tightness and specificity), the current line scored
**5/4.5/4.5/5** versus **5/4/5/4.5** for the best challenger, B5:
“My agent Rio asked me for an API-key screenshot and leaked it. The only thing he
successfully deployed was my credentials.”

**Decision: keep the current line.** B5 had the harsher, directly attributable
failure, but its familiar deployment joke and technical vocabulary lost on the
higher-priority first-read joke criterion. The other challengers had weaker
premises or less surprise: no winnings do not prove rejection or lack of learning,
safety stops can be correct, low funding partly implicates the owner, and the
public/private credential joke repeats its setup. The obituary remains the
clearest concrete reversal. These are editorial scores; no external judging was
performed. Full drafts and notes are in [WORKING_NOTES.md](WORKING_NOTES.md).
